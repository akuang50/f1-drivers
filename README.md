# Paddock — 2026 Formula 1

A premium briefing for the current Formula 1 grid: driver profiles, career history, stats, Grand Prix pages, and clearly labeled race / championship predictions.

Live: https://akuang50.github.io/f1-drivers/

Timing data from [Jolpica](https://api.jolpi.ca/) (Ergast). Portraits from Formula 1 / OpenF1.

## Local

```bash
npm install
npm run dev
```

Then open the Vite URL under `/f1-drivers/` (the production base path).

```bash
npm run build
npm run preview
```
